# Designs

Put screenshots and design exports here.

## How to name files

```
YYYY-MM-DD_screen_short-description_vN.png
```

- **Date** — the day you made it, year first. This keeps files in order.
- **Screen** — one of the names below.
- **Short description** — a few words, lowercase, joined with hyphens.
- **Version** — `v1`, `v2` and so on, if you make more than one.

Use lowercase. No spaces.

## Screen names

`dashboard` · `inbox` · `availability` · `bookings` · `invoices` · `knowledge` · `automations` · `reports` · `settings`

For anything that covers more than one screen, use `overall`.
